## 0. الخلاصة التنفيذية

وُجد في مجلد العمل **مشروعان مختلفان** يجب عدم الخلط بينهما:

1. **مشروع القوالب/النماذج (Attachments):** مجموعة نماذج واجهة معاينة (HTML أحادي الملف + ZIPs + مستندات توجيهية). لا اتصال بقاعدة بيانات، ولا لوحة إدارة فعلية.
2. **المشروع الحقيقي العامل (في مجلد العمل):** `chrvvim-campus/` — تطبيق كامل: خادم Node بلا تبعيات + SQLite + لوحة إدارة + جلسات وCSRF + 3 لغات + PWA + اختبارات. وهو **النسخة الموحّدة** (Superset) المفترض أنها تجمع ميزات الموقع المنشور.

**الموقع المنشور حالياً** على `mr1mohamed1chraim.netlify.app` هو **النسخة القديمة** (بوابة كلية الحقوق + Supabase + gate إنستغرام)، وليس المشروع الموحّد. إذن: المشروع الموحّد **لم يُنشر بعد**، وهذا متوافق مع قاعدة «لا نشر دون موافقة».

**أهم ثلاث نتائج تستلزم قراراً منك:**
- بيانات «الجامعة بالأرقام» داخل قالب المعاينة **لا تطابق** الصفحة الرسمية الحالية للجامعة (أرقام قديمة).
- لائحة المؤسسات الرسمية **متباينة داخل مصدر الجامعة نفسه**: صفحة «مؤسساتنا» تعرض 24 اسماً بينما الصفحة الرئيسية تقول 23.
- المشروع الحقيقي **أُنجز فيه جزء كبير بالفعل** (خادم + لوحة إدارة + أمان)، لكنه **يفتقد** معظم مهام الأمر القطعي (تعدد المؤسسات، ربط دروس YouTube، مساعد الطالب الذكي، منظومة المصادر والتحديث، قائمة المراجعة).

## 2. جرد المشروع الحقيقي: `chrvvim-campus/`

**الحجم التقريبي:** ~7 ميغابايت · **الإصدار:** 2.0.0 · **يحتاج:** Node.js ≥ 22.5

### البنية

```
chrvvim-campus/
├─ server/        خادم Node (بلا تبعيات): index.mjs · seed.mjs · config.mjs
│  ├─ lib/        http · router · security · session · db · validate
│  ├─ routes/     public · auth · admin
│  ├─ services/   audit · ai
│  └─ data/       chrvvim.sqlite (+ wal/shm)
├─ web/           الواجهة (تُنشر ثابتة على Netlify)
│  ├─ index.html  البوابة العامة (SPA بتوجيه hash)
│  ├─ admin/      لوحة الإدارة المستقلة
│  ├─ assets/js/  app · views · data · i18n · store · gate ·
│  │              legal-engine · legal-view · subjects-engine · subjects-view · util
│  ├─ data/       JSON مرجعية (الدليل الأكاديمي، الوثائق، المواد والمقابلات، إعدادات الموقع…)
│  ├─ documents/  10 ملفات PDF رسمية
│  └─ sw.js · manifest.webmanifest · 404.html
├─ docs/          ARCHITECTURE.md + 5 لقطات شاشة
├─ scripts/       check.mjs · smoke.mjs · seo.mjs · fetch-fonts.mjs
├─ tests/         unit.test.mjs · legal-engine.test.mjs
├─ netlify.toml · package.json · .env.example
└─ chrvvim-campus-deploy.zip （حِزمة الواجهة الثابتة الجاهزة）
```

### الميزات المنجَزة فعلياً في الكود

- **عامة:** البحث عن الفوج باللقب (تطبيع عربي/فرنسي)، استعمال الزمن + تصدير `.ics`، المسالك، الدليل الأكاديمي، توزيع الأفواج، مركز الوثائق، حاسبة المعدل، المواد والمقابلات، الإعلانات، إحصائيات، 3 لغات (RTL/LTR)، وضع ليلي، PWA.- **لوحة إدارة:** دخول بجلسة SQLite + CSRF، CRUD للجداول والمواد والأساتذة والقاعات والإعلانات، أدوار (مدير/ناشر/محرر)، سجل تدقيق، نشر جماعي للمسودات، مساعد صياغة إعلانات (LLM أو محلي).
- **الخادم:** HTTP مخصّص، وسائط، رؤوس أمان CSP، scrypt، جلسات HMAC، حدّ معدّل، تحقق صارم من المدخلات، منع Path Traversal.
- **الجودة:** `check.mjs` (أمر بناء Netlify)، `smoke.mjs` (اختبار HTTP شامل)، اختبارات وحدة.

### نموذج البيانات الفعلي (SQLite)

`schedules` · `courses` · `professors` · `rooms` · `announcements` · `admins` · `sessions` · `audit_logs`

> ⚠️ هذا نموذج **كلية واحدة**. لا وجود لـ `institutions` أو `programs` أو `source_checks` أو `review_queue` أو `ai_resources` المذكورة في مواصفاتك.

## 5. فحص Supabase (للموقع الحيّ)

`supabase-config.js` المنشور يحتوي:
```js
window.CHRVVIM_SUPABASE = {
  url: "https://idpafbyefrywjixskvvu.supabase.co",
  anonKey: "sb_publishable_…"   // مفتاح عام (publishable) — لا service_role
};
```

| الفحص | النتيجة |
| --- | --- |
| وجود `service_role` أو أسرار | ✅ لا يوجد — مفتاح عام فقط |
| نقاط النهاية الجذرية (OpenAPI) | ✅ 401 «Secret API key required» (محمي) |
| جداول موجودة ومتاحة للعام | `announcements`، `admins` |
| جداول مواصفاتك (institutions, documents, review_queue…) | ❌ غير موجودة |
| قراءة بيانات كـ anon | ترجع صفر صفوف (`*/0`) — إما فارغة أو محجوبة بسياسات RLS |
| الكتابة كـ anon | **غير محسومة**: الاختبار غير الحاسم (لا صفوف ظاهرة)، فلم يُجرَ أي إدخال فعلي احتراماً لقاعدة «لا تغيير على الإنتاج دون موافقة» |

> **الخلاصة الأمنية:** لا تسريب مفاتيح في الواجهة. لكن **حالة سياسات RLS للكتابة لم تُثبَت من الخارج**، وتحتاج إما جلسة مدير مُصدّقة، أو مراجعة `server/supabase-admin-setup.sql` (المُشار إليه في `admin.html` لكنه **غير موجود** في الملفات المرفقة).

### 6.2 نتائج المقارنة مع القالب (HTML)

- القالب يعرض 29 صفاً = **24 مطابقة للرسمي** + **5 «قيد التحقق»**. هذه المطابقة **صحيحة** ✅.
- الصفوف الخمسة «قيد التحقق» (المدارس الوطنية للتكنولوجيات المتقدمة بالعيون والداخلة، الصناعات الغذائية بيوكرى، كلية العلوم والتقنيات بكلميم، معهد مهن الرياضة) **غير مدرجة** في صفحة المؤسسات الرسمية → تصنيفها صحيح.
- لكن **آلية التصنيف في الكود هشّة**: العلامة مكتوبة يدوياً `off: i<=22 || i===28` بدل التحقق بالمطابقة. أي إدراج/حذف صف سيقلب التصنيف خطأً.
- **تنبيه تسمية**: الموقع الحيّ يستخدم «كلية العلوم القانونية والسياسية»، بينما الاسم الرسمي في دليل الجامعة «Faculté des Sciences Juridiques, Économiques et Sociales — Agadir». يجب توحيد التسمية مع الإشارة إلى الاسم الرسمي.
