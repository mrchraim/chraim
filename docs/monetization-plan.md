# خطة الربح — CHRAIM

## 1) Google AdSense
أماكن مقترحة: أسفل البطل (hero)، بين الأقسام، صفحات المحتوى.
يتم التحميل بعد موافقة المستخدم فقط. ملف ads.txt مع placeholder.

## 2) وحدات تابعة (Affiliate)
مكون "إعلانات" + ملف JSON لإدارة العروض مع rel="sponsored noopener".

## 3) قوائم مدعومة (Sponsored listings)
صفحة مخصصة + باقات إعلانية.

## 4) الاحتفاظ بالزوار
نشرة بريدية/قنوات تواصل لزيادة الزيارات المتكررة.

## تقدير واقعي
يعتمد على حركة المرور خلال موسم التسجيل والامتحانات. التركيز على SEO + تجربة نظيفة.
