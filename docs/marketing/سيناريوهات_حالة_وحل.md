# 🎬 فيديوهات "حالة + حل" (سيناريو واقعي) — 30 ثانية + برومبتات إبداعية
**النيش:** تعليم / مهارات | **المدة:** 30 ثانية | **اللغة:** عربي + English
**الفكرة:** كل فيديو يبدأ بحالة واقعية يمرّ فيها المتابع → يفهم السبب → يحصل على الحل → CTA.
**البنية:** 0–3 الحالة | 3–9 السبب | 9–24 الحل (3 خطوات) | 24–30 CTA

# 🧩 السكربت 1 — الحالة: "بتدرس 3 ساعات وما بتتذكر شي"
**الهاشتاغات:** #دراسة #تعلم #ذاكرة #studytips #learning

| الوقت | عربي | على الشاشة |
|-------|------|-------------|
| 0–3s | "درست 3 ساعات، وبعدها حسّيت إني ما تعلمت شي." | 😩 درست 3 ساعات؟ |
| 3–9s | "المشكلة مو الوقت، المشكلة إنك بتقرأ سلبي." | ❌ وقت ≠ تعلّم |
| 9–15s | "الحل الأول: بعد كل فقرة، سكّر واشرحها بصوتك." | 1️⃣ اشرح بصوتك |
| 15–21s | "التاني: اكتب 3 أسئلة من ذاكرتك، بلا ما تشوف." | 2️⃣ 3 أسئلة |
| 21–27s | "التالت: راجع غداً، مو بكرة." | 3️⃣ راجع غداً |
| 27–30s | "احفظ 📌 وجرّب هالفيديو الجاي." | 🔖 احفظ |

**English:** "Studied 3 hours and learned nothing? The problem isn't time—it's passive reading. Fix: 1) explain out loud 2) write 3 questions from memory 3) review tomorrow. Save 📌."

### 🎨 برومبت توليد الفيديو (سينمائي — عربي):
```
فيديو عمودي 9:16، مدته 30 ثانية، أسلوب modern minimal + cinematic.
المشهد الأول: شاب جالس على مكتب في غرفة خافتة، أكوام كتب، ساعة جدار متحركة بسرعة،
إضاءة دافئة جانبية، جوه ضبابي خفيف (mood: overwhelmed).
الثاني: ينتقل لكادر نظيف بخلفية بيضاء، نص ضخم يظهر "المشكلة مو الوقت".
الثالث: أيقونات خطوة بخطوة تظهر بالتتابع بجانب شخص يشرح بصوت عالٍ.
النهاية: شعار/CTA نظيف. حركة كاميرا بطيئة (slow push-in)، ألوان هادئة (أزرق/رمادي/ذهبي)،
جودة 4K، بلا كلام منطوق (نصوص على الشاشة فقط)، أسلوب MOTION GRAPHICS سلس.
```

### 🎨 Video generation prompt (English):
```
Vertical 9:16 cinematic video, 30s, modern minimal style.
Scene 1: young person at a dim desk, stacks of books, wall clock spinning fast, warm side light,
slight haze, overwhelmed mood. Scene 2: cuts to a clean white background, huge bold text "It's not time"
appearing with a smooth ease-in. Scene 3: step icons animating one by one beside a person speaking out loud.
End: clean CTA logo. Slow push-in camera, calm palette (blue/gray/gold), 4K, no voiceover,
smooth motion graphics, subtle ambient sound.
```

## 🎯 قواعد البرومبت الإبداعي (نصيحة احترافية)
كل برومبت قوي لازم يحتوي 7 عناصر:
1. **الصيغة والأبعاد:** Vertical 9:16، المدة.
2. **الأسلوب:** cinematic / minimal / stop-motion / white-board.
3. **المشهد** بالتفصيل: الشخص، المكان، الأدوات.
4. **الإضاءة والجو:** warm / cool / moody / light haze.
5. **لوحة الألوان:** rainbow محدّد (teal/gold...).
6. **حركة الكاميرا:** push-in / dolly / pan.
7. **النهاية:** CTA + الجودة (4K) + هل يوجد صوت أم لا.

> 🔑 سرّ الإبداع: لا تكتب "فيديو تعليمي"، اكتب **إحساس + استعارة بصرية** (شمعة، بازل، سلّم، فوضى→هدوء).
