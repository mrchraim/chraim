# حالة مشروع CHRVVIM — نسخة التحضير المتقدمة

## الرؤية المعتمدة
- واجهة عامة للطلبة دون الحاجة إلى حساب.
- لوحة إدارة خاصة تتطلب تسجيل الدخول.
- حسابات إدارية متعددة بصلاحيات مختلفة.
- نشر المحتوى بعد المراجعة، مع إبقاء البيانات الأولية مسودات.
- مركز إعلانات وتنبيهات داخل الموقع.
- تصميم يسمح بإضافة خصائص مستقبلية دون إعادة بناء المشروع من الصفر.

## الصلاحيات
| الدور | قراءة المحتوى | إنشاء/تعديل المسودات | النشر/الأرشفة | حذف المحتوى | إدارة الحسابات وسجل التدقيق |
|---|---|---|---|---|---|
| مدير admin | نعم | نعم | نعم | نعم | نعم |
| محرر editor | نعم | مسودات فقط | لا | لا | لا |
| ناشر publisher | نعم | نعم | نعم | لا | لا |

## ما تم تجهيزه في هذه النسخة
- تحديث لوحة الإدارة لإدارة الجداول والمواد والأساتذة والقاعات والإعلانات.
- إضافة إدارة الحسابات وتغيير الصلاحيات وتفعيل/تعطيل الحسابات وتغيير كلمات المرور.
- فرض الصلاحيات في الخادم، وليس في الواجهة فقط.
- إضافة واجهات عامة تعرض السجلات المنشورة فقط.
- إضافة مركز الإعلانات في الصفحة الرئيسية.
- إدراج بيانات السداسي الأول لشعبتي القانون الخاص والعام (14 حصة) ضمن الاستيراد كمسودات.
- إدراج 21 حصة مقدمة للسداسي الثالث للقانون الخاص، وحدود توزيع الأفواج A–N، مع الإبقاء على الفترات غير المحددة كما هي دون تخمين.
- توسيع دليل السداسي الخامس ليشمل ثمانية مسارات/مسالك، بما فيها الدراسات الإدارية والمالية والدراسات السياسية والدولية.
- إضافة واجهة عامة للسداسي الأول، وجداول السداسي الثالث المنشورة، وحدود الأفواج. لا تظهر الحصص قبل نشرها من الإدارة.
- فصل ملف الدليل العام المبسط عن ملف البيانات الكامل المستخدم في الاستيراد، ومنع تقديم ملف الجدول الأولي كملف عام مباشر.
- إضافة تعليمات التشغيل والنشر ومتطلبات التخزين الدائم.

## ما تم فحصه هنا
- فحص صياغة ملفات JavaScript بواسطة `node --check`.
- إضافة فحص ثابت قابل للتكرار لملفات JSON وبعض حواجز الأمان عبر `scripts/check-project.js`.
- تعديل التحقق من صلاحيات الإدارة بحيث يعيد الخادم قراءة الدور وحالة الحساب من SQLite في الطلبات المحمية، لتطبيق التعطيل/تغيير الصلاحيات بدل الاعتماد على نسخة قديمة داخل الجلسة.
- التحقق من ملفات JSON، ووجود شعبتي S1، وحصص S3 المقدمة، و14 فوجاً، وثمانية مسالك في S5.
- تجربة إنشاء بنية جداول SQLite في اختبار مستقل.

## ما لم يتم تأكيده بعد
- لم يتم تشغيل الخادم فعلياً أو تجربة تسجيل الدخول والتعديل والنشر من متصفح حقيقي؛ انتهت مهلة محاولة تثبيت المكتبات في بيئة التحضير.
- لم يتم اختبار الاستضافة أو استعادة نسخة احتياطية.
- لم يتم إجراء مراجعة أمنية مستقلة.
- الإشعارات الحالية إعلانات داخل الموقع وليست إشعارات دفع للمتصفح أو الهاتف.
- توزيع الفرنسية والبيانات الدراسية التي لم يجر التحقق منها رسمياً لا ينبغي نشرها كبيانات مؤكدة.

## ملاحظات على البيانات الأكاديمية
- جميع السجلات الجديدة تُستورد بحالة مسودة `draft` ولا تُنشر تلقائياً.
- الملخص الأكاديمي المقدم من المستخدم ليس بحد ذاته دليلاً على المصادقة الرسمية؛ راجع الأسماء والتوقيت والقاعات، خصوصاً حصص S3 التي تحتوي على تداخلات أو أوقات غير محددة.
- تشغيل `npm run seed` لا يدمج البيانات الجديدة في قاعدة بيانات تحتوي مسبقاً على سجلات؛ استخدم قاعدة جديدة للاختبار أو أضف البيانات عبر لوحة الإدارة لتجنب التكرار.

## الخطوة التالية
تنزيل هذه النسخة، تشغيل `npm install` و`npm run check` وتهيئة `.env` محلياً، ثم تشغيل `npm run seed` مرة واحدة و`npm start`. بعد نجاح الاختبار المحلي نختار استضافة ذات تخزين دائم وننشر النسخة التجريبية.


## تحديث الوثائق المضافة
- تمت إضافة مركز «الوثائق الجامعية» إلى الواجهة مع تصفية حسب السداسي والشعبة.
- أُرفقت 10 وثائق PDF أصلية ضمن `public/documents/`، مع قائمة بيانات `public/academic-documents.json`.
- تشمل استعمال الزمن S3 القانون العام، وS5 القانون المدني والعلوم الجنائية والدراسات السياسية والدولية، وتوزيعات أفواج S3 وS5 واللغتين الفرنسية والإنجليزية.
- ملفات PDF تحفظ محتواها الأصلي؛ لا يتم تعديل أو إعادة تأليف الجداول داخل الوثائق.
