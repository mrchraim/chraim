## 4. ما يظل مؤتمساً بالمؤسسة (Institution-Specific)

| العنصر | التبرير | التنفيذ |
|---------|---------|----------|
| هوية كل مؤسسة (لون، خلفية، شعار) | كل مؤسسة لها طابعها الخاص | إعدادات لكل مؤسسة في `site-config` أو ملف مؤسسة مخصص |
| الجداول والأفواج الخاصة بكل مؤسسة | بيانات أكاديمية مختلفة لكل كلية | ملف بيانات لكل مؤسسة أو سجل في قاعدة البيانات |
| الروابط الرسمية لكل مؤسسة | كل كلية لها موقعها الخاص | روابط رسمية لكل مؤسسة في الإعدادات |
| سنة دراسية وفصل دراسي | قد تختلف حسب المؤسسة | حقول قابلة للتكوين |
| وثائق كل institution | PDF خاصة بكل كلية | مجلد وثائق لكل institution أو فهرس موحد مع تصنيف |
