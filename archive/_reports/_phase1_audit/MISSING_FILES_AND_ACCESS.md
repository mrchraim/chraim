## 4. أدوات وبيئة التطوير غير متوفرة

| الأداة | الحالة | الأثر |
|-------|-------|-------|
| Node.js | ❌ غير مثبتة في بيئة التشغيل | لا يمكن تشغيل `npm run check`, `npm run smoke`, `npm test` محلياً |
| Netlify CLI | ❌ غير مثبتة | لا يمكن النشر على Netlify عبر سطر الأوامر |
| npm / pnpm | ❌ غير مثبتة | لا يمكن إدارة تبعيات المشروع (مع أن المشروع يدّعي عدم وجود تبعيات خارجية) |

**ملاحظة:** المشروع يدّعي "بلا تبعيات خارجية" (Node built-in فقط)، لكن التشغيل يحتاج Node.js ≥ 22.5. بيئة التشغيل الحالية لا تحتوي على Node.js.
