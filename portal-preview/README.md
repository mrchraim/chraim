# CHRVVIM Campus — بوابة جامعة ابن زهر (معاينة محلية)

نسخة مطوّرة من البوابة: **كل مؤسسة لها بابها الخاص** (صفحة مستقلة)، والمعطيات مستخرجة من
**المنصات الرسمية** لجامعة ابن زهر. لم يُنشر أي شيء على أي نطاق.

## البنية

```
portal-preview/
├── index.html                     ← الصفحة الرئيسية: دليل 24 مؤسسة + بحث وتصفية
├── etablissements/                ← 24 صفحة مستقلة (باب لكل مؤسسة)
│   ├── flsh-agadir.html
│   ├── fsa-agadir.html
│   ├── ... (24 ملفاً)
│   └── est-dakhla.html
└── build/                         ← ملفات التوليد (لا تُفتح في المتصفح)
    ├── data.json                  ← كل المعطيات الموثّقة (المصدر الوحيد للحقيقة)
    ├── style.css                  ← التنسيق المشترك
    ├── app.js                     ← الوضع الليلي + البحث/التصفية
    └── generate.ps1               ← مولّد الصفحات الثابتة
```

## إعادة التوليد

```
powershell -NoProfile -ExecutionPolicy Bypass -File build/generate.ps1
```

ينتج `index.html` و `etablissements/*.html` من `build/data.json`.
ملاحظة: ملف `generate.ps1` محفوظ بترميز **UTF-8 مع BOM** ليقرأه PowerShell 5.1 بشكل صحيح.

## قواعد الدقة المطبَّقة

- لم تُخترع أي مؤسسة أو جدول أو أستاذ أو رابط.
- حيث لا يتوفر نص عربي رسمي، عُرض **عرض عربي أمين** للنص الفرنسي الرسمي.
- كل مؤسسة تُظهر مصدرها وتاريخ فحصها.
- «معهد مهن الرياضة» (IMS) غير وارد في القائمة الرسمية المنشورة، لذا يُعرض في قسم
  منفصل «خارج القائمة الرسمية» مع حفظ رابطه دون أي معطيات غير مؤكدة.
- **لم يُغيَّر أي رابط** من روابط النسخة الأصلية (29 رابطاً) — تم التحقق برمجياً.

## ما لم يُنجز (يحتاج قرار المالك)

- لم يُنشر الموقع (لا Netlify، لا DNS).
- لم يُربط بقاعدة بيانات Supabase.
- لم يُضف مساعد ذكاء اصطناعي (نموذج معاينة فقط محلي).
- جداول استعمال الزمن والدروس الحالية غير متوفرة من مصادر رسمية بعد.
