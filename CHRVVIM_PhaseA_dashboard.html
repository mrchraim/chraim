4 فحص Supabase

  • لا يوجد service_role — مفتاح عام sb_publishable_… فقط.
  • نقاط الجذر محميّة: 401 «Secret API key required».
  • جداول موجودة: announcements · admins.
  • جداول مواصفاتك غير موجودة إطلاقاً.
  • القراءة كـ anon ترجع صفر صفوف.
  • RLS للكتابة غير مُثبت — لم يُجرَ أي إدخال احتراماً للإنتاج.

8 قيود بيئة التشغيل

  • Node.js غير مثبّت (node · npm · npx مفقودة) ← تعذّر تشغيل check.mjs وsmoke.mjs والاختبارات.
