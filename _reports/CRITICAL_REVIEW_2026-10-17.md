## 1) المنهجية: قِس، لا تخمّن

الـ CSS مكوّم في 10 طبقات متراكبة داخل وسم واحد (78,788 حرفاً، 67 إعادة تعريف `:root`، 219 `!important`). لذلك القراءة السطحية مضلِّلة — كان مكتوباً مثلاً `#bgfx{animation:bgPan 140s infinite}` ثم لاحقاً `.ticker,.hero-fx,#bgfx{animation:none!important}`، فبدا كأن الحركة موقوفة.

لذلك قستُ **ما يعمل فعلاً في المتصفح**: `document.getAnimations()` ou `getComputedStyle`. النتيجة: الحركة **لم تكن** موقوفة — 6 حركات لا نهائية كانت تعمل.

### ب) إمكانية الوصول (Lighthouse)
1. `color-contrast` — `.wa-kicker` بلون `rgb(155,122,46)` على `rgb(255,254,251)` = **~3.4:1** (فشل AA).

   - **38 رابط `.wa-join`**: الاسم الميسَّر `"الانضمام إلى مجموعة الشعبة X في واتساب"` لا يطابق النص المرئي `"انضم عبر واتساب ↗"`.

### ج) «تصميم جاهز» / مكوّنات مستهلكة
- **15 تبويباً بأيقونات Emoji** (🧠 ✍️ 🔎 …) — نظام أيقونات غير متّسق، يختلف شكله بين الأنظمة.

### د) الماركب والاستجابة

- لا يوجد أي تنسيق مخصّص للشاشات الصغيرة جداً للبطاقات/التبويبات.

## 3) ما أصلحته (مباشرة في الكود)

### 1. نظام أيقونات SVG بدل الـ Emoji — إصلاح جذري
- `index.html`: استبدال 15 emoji بـ `<svg class="tab-ic">` (خطوط stroke بنمط موحّد 24×24).
- `app.js`: تجريد الـ emoji من **15 قيمة** `tab.*` × 3 لغات (`ar/fr/en`).
- `app.js` (السطر المُصلَح): بدل `b.textContent = …` → تحديث **نص العنوان فقط** مع **الحفاظ على الـ SVG**:
  ```js
  var lbl=t('tab.'+b.dataset.p); var ic=b.querySelector('.tab-ic');
  if(ic){ var tx=b.querySelector('.tab-tx'); if(!tx){tx=document.createElement('span');tx.className='tab-tx';b.appendChild(tx)} tx.textContent=lbl } else { b.textContent=lbl }
  ```
  → الترقية تدعم التقدّم التدريجي، وتعمل مع تبديل اللغة، ولا تُمحى.

### 2. إصلاحات الوصول
- `.wa-kicker` → `#6b5310` (تباين ~7.3:1 ✅) + بديل فاتح للوضع الداكن `#e9cb6b`.
- إعادة صياغة **38** `aria-label` لتبدأ بالنص المرئي: `انضم عبر واتساب ↗ — <الاسم>` (استخرجتُ الاسم آلياً من الـ label الأصلي، دون أي نص مُختلق).
- حذف `aria-label="CHRVVIM"` من شعار `a.ab-brand` (النص المرئي نفسه أصبح الاسم الميسَّر).

### 3. تقليل كلفة الحركة (6 → 1)
- إيقاف `bgPan`, `orbFloat` (×3), `aur`, `gradientShift`, `shim` — مع إبقاء العناصر كعناصر زخرفية **ساكنة** (المظهر يُحافظ عليه).
- إبقاء `tick` (شريط الإعلانات المتحرك — حركة وظيفية) مع تبطيئها إلى 64s + **توقف عند المرور/التركيز**.

### 4. الأداء
- إضافة `defer` للسكربتات الحاجبة الستة (تحقّقتُ أن السكربتات المضمّنة لا تعتمد عليها، فالترتيب محفوظ).

### 5. إزالة الأنماط المضمّنة
- نقل 5 أنماط `style=""` إلى قواعد CSS بأسماء (`#campus-announcements`, `.footer-links`, `#detailBox`, `#gate .muted`, `#campus-announcements h2`). **الناتج: 0 أنماط مضمّنة.**

### 6. استرجاع التفاعلات الدقيقة (Micro-interactions)
- إعادة `transition` لمدة `0.18s` للأزرار/البطاقات/التبويبات + `hover` (رفع 2px) و`active` — **مشروطة بـ `prefers-reduced-motion: no-preference`**.

### 7. تنسيق الاستجابة
- شريحة `≤480px`: تبويبات أصغر، بطاقات واتساب تُصبح عمودية، زر الانضمام بعرض كامل، هوامش أنسب.
- شريحة `≤360px` إضافية.

### 8. حماية مستقلة للحركة المُقلَّلة
- حاجز واحد `@media (prefers-reduced-motion: reduce)` يوقف كل الحركات/الانتقالات.

### 9. النسخ المؤقت
- `sw.js`: اسم الكاش `chrvvim-shell-v5` → `v6` (تسليم التحديث للزوار).

> **الطبقة المُضافة** كلها في `<style id="cc-polish">` قبل `</head>` — أي **آخر ورقة في التتابع** (لأن الـ `<style>` الأصلي في الموضع 3561 والملفات الخارجية في 82450+). لم أعِد كتابة الـ CSS القديم إطلاقاً — فقط طبقة تحسين غير مُدمِّرة.

## 5) ما يبقى (بأمانة — لم أُصلحه ولم أدّعِ إصلاحه)

1. **الدَّين المعماري للـ CSS (الأهم):** 78KB داخل وسم واحد، **67** إعادة تعريف `:root`، **219** `!important`، وقواعد متناقضة (`.tabs{display:none!important}` ثم إعادة إظهاره). هذا أصل «العادية» في المكوّنات. توحيده يستلزم إعادة هيكلة + اختبار انحدار بصري — ولم تتوفر لقطات شاشة. **أوصي بجولة مخصّصة للتوحيد.**
2. **Emoji متبقية في أزرار داخلية** (مثل «🗓️ عرض استعمال الزمن»، «⭐ احفظ فوجي»، وزر «✅ أكمل البحث») مصدرها i18n — تُوحَّد مع نظام الـ SVG في متابعة.
3. **استراتيجية Service Worker:** `cache-first` حتى لوثيقة HTML → قد يرى الزوار نسخة قديمة. رفعت رقم الكاش، لكن الأفضل **network-first لـ HTML**.
4. **`founder.jpg` 900×900 يُخدَم لصورة 42px** — يُفضّل إصدار مصغّر (256px ~15KB بدل 139KB).
5. **كود CSS ميت** (طبقات مُلغاة) يزيد الصيانة والتضليل.
6. **38 رابط واتساب مكتوب يدوياً** برموز دعوة حقيقية داخل HTML عام — قرار صاحبه.
7. **تجميع/تصغير JS** (‏~250KB غير مُصغَّرة) — Cloudflare يمكنه ذلك عند النشر.
8. **ثلاث بنى متباعدة:** `chrvvim.talib.aga.ma` (حزمة)، `chrvvim-campus/web` (معياري)، `_archive/site2-…` — تحتاج قرار توحيد.
