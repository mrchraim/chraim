# نظام الإدارة المتكامل | Management System

نظام إدارة متكامل مع قاعدة بيانات ولوحة تحكم ثنائية اللغة.

A full-featured management system with database and bilingual admin dashboard.

---

## المكونات | Stack

| المكوّن | التقنية |
|---------|---------|
| الواجهة | HTML / CSS / JavaScript |
| قاعدة البيانات | Supabase (PostgreSQL) |
| المصادقة | Supabase Auth |
| الاستضافة | Cloudflare Pages |
| الكود | GitHub |

## المميزات | Features

- ✅ تسجيل دخول / إنشاء حساب
- ✅ لوحة تحكم مع إحصائيات مباشرة
- ✅ إدارة المشاريع (CRUD)
- ✅ إدارة المهام مع الأولوية والاستحقاق
- ✅ إدارة المستخدمين والأدوار
- ✅ سجل النشاط
- ✅ ثنائية اللغة (عربي/إنجليزي) مع دعم RTL
- ✅ تصميم متجاوب للموبايل

## قاعدة البيانات | Database

7 جداول:
- `roles` - الأدوار والصلاحيات
- `profiles` - الملفات الشخصية
- `projects` - المشاريع
- `tasks` - المهام
- `activity_log` - سجل النشاط
- `settings` - الإعدادات
- `documents` - المستندات

## التشغيل | Setup

1. افتح `index.html` في المتصفح
2. أنشئ حساب جديد
3. سجل الدخول للوصول للوحة التحكم
