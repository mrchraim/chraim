# tools/

أدوات مشروع **CHRVVIM Campus** (تعمل خارج وقت التشغيل، لا تُحمَّل في المتصفح).

## `scraper.py`
يجلب الإعلانات الرسمية من مواقع مؤسسات جامعة ابن زهر–أكادير ويكتبها بصيغة الموقع.

```bash
pip install requests beautifulsoup4
python tools/scraper.py
```

المخرجات:
- `data/announcements.json` — النتيجة الخام للجلب.
- `announcements.json` (جذر الموقع) — **يُدمج** الجديد فقط مع الموجود، بلا حذف، مع إزالة التكرار حسب الرابط/العنوان.
